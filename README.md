## 🚀 Featured Projects

### 🗺️ Spatial Analysis: Deprivation & Public Transport Accessibility – Christchurch
Integrated NZDep2023 deprivation scores, Stats NZ meshblock data, and
Christchurch City Council open data to analyse transport accessibility
across Christchurch. Applied GWR, spatial regression, and DBSCAN clustering
to identify priority areas for intervention.
`Python` `GeoPandas` `ArcGIS Pro` `QGIS` `GWR` `DBSCAN`

### 🤖 LLM-Based Span Annotation Pipeline – Deep-Sea Mining Policy
End-to-end pipeline to extract structured entities and arguments from
large PDF policy corpora using 15 domain-specific label categories.
Best classifier: Micro-F1 = 0.713 (GPT-OSS 120B + DSPy BootstrapFewShotWithRandomSearch).
Featured on supervisor Dr Geoff Ford's research page:
👉 https://geoffford.nz/bits/deep-sea-mining
`Python` `DSPy` `LLMs` `spaCy` `JSON`

### 📊 Exploratory Spatial Data Analysis – Deprivation Patterns in NZ
Identified spatial clustering using Moran's I; compared deprivation
patterns between Christchurch and Wellington; explored links with
Māori population distribution.
`ArcGIS Pro` `GeoDa` `Python`
